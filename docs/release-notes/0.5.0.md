# CAPT 0.5.0 Release Notes

For the Japanese version, see `0.5.0.ja.md`.

## Webhook & Certificates
- Aligned Admission/Conversion webhooks with Kubebuilder best practices; resolve Service references via kustomize nameReference/namespace mapping.
- Added name-merge patches to `capt-*-webhook-configuration` to enforce `clientConfig.service = capt-webhook-service/capt-system`.
- Use cert-manager `inject-ca-from` annotations to inject CA into MWC/VWC and CRD conversion webhooks.
- Automated caBundle readiness checks via `make wait-ca`.

## Conversion Webhook
- Removed manual duplicate registration of `/convert`; rely on controller-runtime auto-registration.

## e2e Improvements
- Added explicit readiness waits before applying resources that trigger admission (Deployment rollout, TLS Secret, Service Endpoints, small settle time) to avoid connection refused.

## API Samples Updated (v1beta2)
- Cluster upgraded to v1beta2 (`spec.topology.classRef.name`).
- ClusterClass reference fields migrated to `*.templateRef`.
- KubeadmConfigTemplate updated to v1beta2 with a minimal no-op configuration.

## Heads up (Follow-ups)
- Strengthen immutability validation on `CAPTControlPlane` (reject forbidden updates).
