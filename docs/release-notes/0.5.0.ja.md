# CAPT 0.5.0 リリースノート

本ページは日本語版です。英語版は `0.5.0.md` を参照してください。

## Webhook と証明書
- Admission/Conversion Webhook を Kubebuilder 標準に準拠させ、Service 参照は kustomize の nameReference/namespace で解決。
- `capt-*-webhook-configuration` に名前マージパッチを追加し、`clientConfig.service` を `capt-webhook-service/capt-system` に強制。
- cert-manager の `inject-ca-from` アノテーションで、MWC/VWC と CRD conversion へ CA を注入。
- `make wait-ca` で caBundle 注入まで待機する仕組みを追加。

## Conversion Webhook
- `/convert` の手動登録を削除し、自動登録に統一（重複登録のパニックを解消）。

## e2e 改善
- Admission 実行前に Webhook 起動完了を待つ手順を追加（Deployment ロールアウト、TLS Secret、Endpoints、短い待機）。

## API サンプル更新（v1beta2）
- Cluster を v1beta2（`spec.topology.classRef.name`）へ更新。
- ClusterClass の参照フィールドを `*.templateRef` に変更。
- KubeadmConfigTemplate を v1beta2 に更新（no-op 最小構成）。

## 既知の注意点（今後の改善候補）
- `CAPTControlPlane` の不変項目に対するバリデーション（Update Forbidden）を強化予定。
